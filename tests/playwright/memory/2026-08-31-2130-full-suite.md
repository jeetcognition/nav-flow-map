## Learnings for next run

- **Check `jeet-devin-qa`'s Monthly ACU limit before the run.** A limit of 0 makes every
  session-spawning spec fail with no visible error, which reads like a broad app outage. The
  Organizations manage dialog restores it (empty value = `No limit`).
- Playbook create footer says `N chars`, not `N characters`.
- The MCP marketplace has no "Not installed" badge any more: not-installed servers carry no badge
  and their card routes to `/settings/mcp-marketplace/setup/<id>`; installed ones show `Enabled`.
- Monaco on the Blueprint tab mounts with a placeholder buffer, so two same-tick reads can both
  return `#`. `blueprintText()` now requires two reads a polling interval apart to agree.
- Enterprise settings hub now lists Learning, Usage Policies and Devin Coach, and no longer lists
  Skills & Rules; `/settings/enterprise-skills` 404s.
- Re-run targeted specs with `--project=authenticated --no-deps` so a re-run does not request a new
  OTP; the admin storage state stayed valid all run.
