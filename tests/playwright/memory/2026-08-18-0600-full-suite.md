## Learnings for next run

- Always chunk the canonical run and re-authenticate before each chunk: a single
  uninterrupted `npx playwright test` outlives the admin session and produces dozens of
  false failures ("Target page, context or browser has been closed").
- Live tenant state is not a fixture. Link state, MCP inventory, disabled switches and
  optional tabs all changed under the tests this run; page objects should expose state
  readers (`isLinked`, `isSwitchDisabled`, `hasOutpostsTab`) and specs should branch on
  them, annotating unexercised paths as `not_tested`.
- Before blaming a route pattern, log `framenavigated`: ORGSEL-REG15 looked like a URL
  spelling drift and was actually an app-side redirect loop.
- Provision a member credential (`.auth/member.json`) and a GitLab token with write
  access; those two gaps alone cost 8 tests every run.
