## Learnings

- F-07 is now 3 days old and dominates the suite (147/191). Until it is fixed, per-area Playwright
  results are not informative; the browser sweep is the only signal for those areas.
- Sidebar navigation followed by native F5 does not trigger F-07; the redirect is specific to the first
  load of an enterprise settings deep link. A future mitigation in `page.goto` helpers (retry via hub
  → sidebar) would mask the bug and is deliberately **not** applied.
- Canonical environment route is `/settings/enterprise-environment`; `/settings/environment` is an alias
  that does not prove the blueprint page loaded.
- F-07 also kills `finally` cleanups → leftover `qa-temp-*` data accumulates and produces cascades
  (ROLE-REG01 today, ORG-REG08/11 yesterday). A periodic cleanup pass for `qa-temp-*` records is
  recommended (65 knowledge notes, 19 playbooks, 3 orgs currently).
- Reusing `.auth/admin.json` in the desktop Chrome via CDP avoids OTP contention between the suite
  and the browser sweep.
