  intermediate method/type chooser; page objects should walk chooser steps defensively.
- Long single-worker runs degrade the admin session (401s on API replays late in the
  run) — chunk the run or re-auth mid-run.
- Provision `DEVIN_MEMBER_EMAIL` and a working GitLab fixture token; they account
  for ~12 failures every run.
