## Learnings for next run

- **Always restore the ACU limit.** A leaked `0` on `jeet-devin-qa` fails every
  session-spawning test (~10) with symptoms that look like product bugs. Check it first when
  sessions hang at "Setting up…".
- `Start scan` and `Create profile` are both **staged choosers** now: Start scan → "Set up
  manually"; Create profile → "Create manually" → "Discover profile" → a full-page form (not
  a dialog) at `/security/profiles/create?mode=discover&scan_type=security`.
- Sidebar section labels sit inside an extra wrapper element: anchor header controls on
  `[data-slot="sidebar-label-row"]`, not on the label's parent.
- The sidebar has two session groups — `Participated` (rows offer "Remove from
  participated") and `Recent` (rows offer "Archive"). Any "recent session" helper must scope
  to the Recent `[data-slot="sidebar-group"]`.
- Secret editing is write-only, not note-only: the banner reads "Values are write-only" and a
  blank value keeps the stored one.
- Deep links to the sub-org Security page still bounce to the sub-org home; navigate via the
  sidebar. The page itself now lives at `/org/<suborg>/security` (`routes.security()`).
- `app/src/types.ts` already fails root `prettier --check` on `main` — unrelated to this run,
  but it makes the root format gate red.
