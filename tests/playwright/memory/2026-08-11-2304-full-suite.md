## Learnings for next run

- Run the suite spec-by-spec (setup re-runs per chunk). A single `npx playwright test` invocation
  outlives the QA session and produces cascading, uninterpretable failures after ~30 minutes.
- Table name cells now carry the row's selection checkbox — never match a row by the cell's
  accessible name; match on the exact cell text instead.
- Dialog inputs no longer have stable ids; use `getByLabel` inside the dialog.
- Do not hard-code tenant counts (MCP catalogue, org totals) — read them and assert stability.
- Add `DEVIN_MEMBER_EMAIL` to the scheduled `.env` or the `member` project will fail rather than
  skip.
