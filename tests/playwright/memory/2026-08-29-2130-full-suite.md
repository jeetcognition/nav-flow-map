## Learnings for next run

- Never name enterprise members or fixed org counts: the `cog-enterprise-qa` membership table
  drifts between runs (Albert Han lost his organization since 2026-08-27). Discover the row shape.
- The org-count popover uses singular "1 member" for single-member orgs — plural-only regexes fail.
- Preferences dropdown targets must be derived from the live option list; a previous run's value
  (or an admin change) can already equal a hard-coded target and kill the pre-condition assertion.
- 6 chunks (down from 10) did **not** save the OTP-dependent login tests; the shared inbox is the
  binding constraint, not the chunk count.
- The session-spawning E2E cases (`ECON-E2E01`, `KNOW-E2E01`, `PLAY-E2E01`, `GUARD-REG04`, APP-5
  trio) have now been red for four consecutive runs; they cannot discriminate app defects until the
  tenant can actually run agent sessions.
