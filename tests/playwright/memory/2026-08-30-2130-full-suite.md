## Learnings for next run

- Membership org counts and personal-preference selections are live tenant data: specs must read
  them from the page (`MembershipPage.memberOrgCounts`, `PrefsPage.optionLabels`) instead of
  hard-coding names/values.
- The org-count popover says "1 member" (singular) for single-member orgs — regexes need `members?`.
- Assistant messages are reachable by role: `group "Devin message"`, with the response text as
  paragraphs. The old `[class*="message-history--item"]` wrapper also matched non-message rows and
  picked up an element with no `.prose-main` child.
- `STOOL-SMK01` shares the newest session with earlier E2E specs, so the tool panel is rarely
  empty — the spec now closes open tabs to reach the empty-panel state it asserts on.
- OTP quota is the binding constraint on a full run: probe the saved storage state before
  re-authenticating (`.auth/admin.json` stayed valid for the whole run this time).
