## Learnings for next run

- Auth1 is now hosted by the enterprise app itself: anonymous routes land on
  `/auth/login?redirect=…`, never `auth.beta.devin.ai/u/login`. Use `LOGIN_URL_PATTERN`.
- The verification step has no resend button — go `Back` and resubmit the email.
- OTP auto-submits after the sixth digit, so `Continue` may already be disabled; type with the
  keyboard rather than `fill()` if a server-side invalid-code path must be exercised.
- Organizations renamed "Billing cycle" + "ACU limit" to a single "Monthly ACU limit" column,
  and the create-form input's accessible name changed to match.
- Applied schedule triggers render a frequency chip plus hour/minute selects, not a single
  "Every day at 9:30 AM" button.
- The admin session does not survive a full 366-test run; chunk the suite with a fresh
  `auth.setup.ts` before each chunk (see the chunk pattern in the artifacts folder).
- Agent-session E2E tests (`*-E2E01`, playbook/automation event checks) need far longer than
  their current timeouts on this tenant; treat them as inconclusive unless given a long window.
