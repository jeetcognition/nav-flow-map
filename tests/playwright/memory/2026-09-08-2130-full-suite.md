## Learnings for next run

- Run the full suite immediately after `auth.setup` with `--no-deps`; a second OTP within the
  same window trips the tenant rate limit and cascades into ~60 console-error assertions. Consider
  spacing AUTH-\* specs or asserting console errors excluding `team-referral` 429s only after a
  product decision.
- Automations create form is a `dialog "Create automation"` (portal), edit form is in `main`;
  `AutomationsPage.form` covers both. Mention/macro menus must be driven by keyboard
  (`pickMentionOption`); `Escape` in the editor closes the whole sheet.
- `deleteAutomationByName` no longer re-enters via the sidebar when the test already ended on
  the list (APP-17 hangs).
- GitLab QA project `software-quality-assurance-group/...` is not connected to the tenant and the
  token returned 401 — verify `GITLAB_QA_API_TOKEN` before trusting REPO-\*/REV-E2E01 results.
- `/review` alternates between "Access denied" and the Review UI depending on prior navigation.
