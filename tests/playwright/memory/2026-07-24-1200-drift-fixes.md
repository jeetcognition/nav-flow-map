# Run memory — 2026-07-24 headed Chromium run + drift fixes

## Scope

Full-suite headed Chromium run (stopped at user request around test 86 /
e-infra), followed by targeted re-runs with fresh auth to triage failures and
verify fixes.

## What failed and why

### Test-side UI drift (fixed in this change)

- **ENV-SMK01 / ENV-SAN01**: the enterprise Environment page was redesigned —
  main tabs are now Rollout (default) | Configuration | Blueprint | Outposts.
  The "Golden snapshot (legacy)" tab is gone. Specs/page object updated.
- **ENV-REG04 / ENV-REG05**: the legacy snapshot tab and its version-history
  surfaces no longer exist; both now skip conditionally when the tab is absent.
- **ENV-REG02**: `blueprintText()` could capture a partially rendered Monaco
  buffer; it now waits until two consecutive reads agree.
- **AUTO-REG01**: the GitHub Issue-comment trigger shows "Connect GitHub to use
  this trigger." when GitHub is not connected instead of the public-GitHub
  caveat; the assertion accepts either configuration reveal.
- **COMP-REG02**: the composer Add-context menu no longer has a separate
  "Send secrets" item (only "Secrets"); removed from the expected list.
- **PLAY-REG07**: the playbook detail page after saving is a read-only view
  that renders the macro as text with a copy button, not an input.
- **SUB-RV-SMK01 / review page object**: the first-visit "Devin Review" intro
  dialog was replaced by an inline "Unlock the full experience" card whose
  dismissal persists across visits; the page object and spec handle both.
- **REV-SAN01/SAN02**: the "All hosts" filter was removed from Review settings
  (only "All modes" remains); locator and assertions removed.

### QA data restored (no code change)

- `jeet-test-org` had been **deleted** from the QA tenant; recreated with
  ACU "No limit" (ORG-\* tests depend on it).
- `jeet-devin-qa` had its billing-cycle ACU limit stuck at **0**; restored to
  "No limit". This appears to have been the cause of the session-creation
  cluster (composer Send not creating sessions; COMP tests pass again after
  the restore).
- Two stale roles `qa-temp-edge-…-🔒-<script>…` (leftovers from an edge test)
  broke ROLE-REG01's 🔒 no-match search; both deleted.

### Remaining genuine application/backend issues (NOT patched around)

- Intermittent **HTTP 500** resource errors on Organizations, Roles,
  Guardrails, Connections (MCP tab), and Infrastructure pages fail the
  console-error assertions (ORG-REG05/07, ROLE-REG01, GUARD-SMK01/SAN01/…,
  ECON-SAN02/REG02, INFRA-REG01). Backend instability on the QA tenant.
- **INFRA-SMK01/SAN01**: Infrastructure heading not rendering (needs re-check
  once the 500s settle).
- **REV-SAN02**: the "Select repositories" dialog renders no repository rows —
  reproducible on Chromium; likely a product defect.
- **API-REG03/04**: service-user create/delete stalls (~2 min timeouts).
- **ANAL-REG02/E2E01**: organization option not clickable in the analytics
  filter (needs deeper investigation; may be timing under headed mode).
- Auth session still expires ~30–35 min into long runs; full runs need a
  mid-run re-auth.

## Decisions

- No assertions weakened for the 500-error failures; they document real
  backend problems.
- Golden-snapshot tests skip (not deleted) in case the surface returns.
