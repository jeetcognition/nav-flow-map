## Learnings for next run

- **Auth expiry**: the admin storage state stops working after ~30–35 min, so a single
  `npx playwright test` pass cannot finish. Run the suite in spec chunks (the setup project
  refreshes admin state between chunks) and keep `specs/authenticated/e-api.spec.ts` +
  `e-conn.spec.ts` in a chunk of their own — they were the pair most often dropped.
- **Radix menus re-mount while settling.** Pointer `hover()`/element-scoped `press()` on trigger
  submenus detaches mid-action ("element was detached from the DOM", `<html>` intercepts pointer
  events). Drive menus by keyboard and read focus from `document.activeElement` at page level.
- **Closed popovers keep their options mounted.** Filter `getByRole("option")` to visible, and wait
  for `toHaveCount(0)` between picks.
- **Never pin live data**: MCP marketplace count, the relative "After <date>" chip, session search
  terms, knowledge entry names and repository permission rows all drifted. Derive them at runtime.
- **Integration-gated controls**: provider trigger types (Slack/Jira) and the Slack notifications
  switch appear/enable only when that integration is connected — assert the gated behaviour instead
  of assuming the connected state.
- `ALT_SUBORG` fixture `fri-5` was not visible in the org list during this run; the 2026-08-17 run
  found it is only paginated out of the org menu's first page, so `fri-5` stays the fixture and the
  menu is searched instead.
