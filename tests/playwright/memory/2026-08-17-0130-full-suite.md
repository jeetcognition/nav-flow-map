## Learnings for next run

- QA data drift is the single largest failure source this run: the org formerly
  named `fri-5` is now `xfri-5` (slug unchanged). Page objects now search before
  interacting, so a rename no longer breaks the suite, but `ALT_SUBORG_NAME` should
  be set explicitly in `.env` if the display name changes again.
- The enterprise landing grid and the top-left org dropdown both render only the
  first ~16 organizations; anything else needs their search controls.
- Admin auth expires ~35 minutes into a run. Long runs must re-authenticate; the
  per-spec runner (`npx playwright test <spec>` with the setup project) is the
  reliable pattern until a refresh is built into the fixtures.
