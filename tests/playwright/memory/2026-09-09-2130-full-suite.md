- Analytics org filter is now a multiselect `dialog` with the pinned "All organizations" option
  outside the `listbox`.
- ECON-\* MCP specs need a product decision: MCPs live under `/org/<slug>/customize` now.

  bugs (TC-ENV-016/017); keep reporting both views.
