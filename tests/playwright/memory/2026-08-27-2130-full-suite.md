## Learnings for next run

- The enterprise Sessions page appends its default filter query (`creator`, `archived`,
  `updatedDate`) to the URL after mount; never anchor a `waitForURL` regex with `$` for it.
- The sidebar Organizations list is fetched after the landing page paints: always use a
  web-first assertion before counting rows or clicking `Load more`.
- 10 chunks (down from 15) still exhausts the OTP quota — the three `AUTH-REG0*` tests and
  `MEMB-E2E01` remain collateral damage of re-authentication.
- E2E cases that wait on a spawned agent session (`ECON-E2E01`, `KNOW-E2E01`, `PLAY-E2E01`,
  `PLAY-REG12`, APP-5 trio) have now been red for three consecutive runs because sessions stay in
  setup on this environment; they need either a longer window or a healthy backend before they can
  discriminate app defects.
