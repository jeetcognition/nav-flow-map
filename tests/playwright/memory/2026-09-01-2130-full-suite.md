## Learnings for next run

- The enterprise build links to `docs.devinenterprise.com`, not `docs.devin.ai`. Assertions now go
  through `DOCS_ORIGIN` / `DOCS_URL_PATTERN` in `support/paths.ts` (overridable via `DOCS_ORIGIN`).
- Playbook mention options are labelled with the **macro** (`!roaster_hulk`), while the inserted
  chip is labelled with the **playbook name**. Never hard-code a playbook that only exists as
  shared QA data — read one from the Playbooks list instead.
- Hiding an MCP from the enterprise marketplace is a two-step confirm; the modal removes the
  switch from the accessibility tree while it is open.
- `jeet-devin-qa` started this run with `No limit` ACU, so none of yesterday's cascade recurred.
- The shared enterprise carries a lot of leftover `qa-temp-*` playbooks/knowledge from earlier
  runs — cleanup in those specs is not reliably completing.
