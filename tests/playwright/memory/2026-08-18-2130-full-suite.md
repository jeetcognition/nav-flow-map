- Assertion: `expect.poll(usageIncludesSession(...)).toBe(true)` — 120 s poll on the
  note's `analytics/sessions` endpoint.

  ("pineapple" → reply `KNOWLEDGE-TRIGGER-CONFIRMED`); start a session in `jeet-devin-qa`
  whose prompt contains "pineapple"; wait for the session response to end with
  `KNOWLEDGE-TRIGGER-CONFIRMED` (proves the note was retrieved and applied); open the
  note's detail page → Usage.

  session that retrieved the note.

  120 s poll. Reproduced 6/6 across two 3× runs, including after deleting a stale
  duplicate note. Endpoint shape verified unchanged via an authenticated probe, so this
  is backend attribution, not selector or schema drift.
