## Learnings for next run

- Preserve the canonical full-run result and report directories before any focused rerun.
- Reuse a validated admin storage state to reduce OTP requests, but keep fresh-request timestamp
  filtering for tests that intentionally exercise authentication.
- The QA auth endpoint rate-limits repeated email starts; auth regression repeats need a larger
  interval or an environment-supported OTP test fixture.
- Shared-tenant mutation tests must capture and restore the exact original value in `finally`.
- Live preference values and enterprise locks cannot be treated as fixed preconditions.
- A member test identity, healthy GitLab token/repository fixture, connected Slack/GitHub
  integrations, and session quota headroom are required for complete discrimination.
- The enterprise UI shows a repeated pattern of enabled submit buttons with invalid or empty input;
  future exploratory runs should verify server-side rejection only on an approved disposable
  target.
