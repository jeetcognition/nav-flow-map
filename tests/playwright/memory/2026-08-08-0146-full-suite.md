## Learnings for next run

- The admin OTP session dies ~35 min in; run the suite in batches of 3–5 spec files so each
  batch re-authenticates, and expect ~45 min end to end.
- `test-results/` (including `results.json`) is wiped at the start of every run — copy artifacts
  out of it before starting the next batch or the failure evidence is lost.
- Radix listboxes overlay the dialog they belong to: always select through the open listbox and
  wait for it to close, otherwise the submit click retries until the test times out
  (the API-REG03 "backend stall" seen since 2026-07-24 was this, not a backend problem).
- Command-palette options are named `Go to: <target>` and only render once the combobox has a
  query.
- The QA tenant currently has no skill invocations and no knowledge-usage sessions; data-driven
  assertions must derive their inputs from live rows.
- The Environment page no longer has an Outposts tab; Security profile creation gained a
  Discover/Ingestion step.
